Debian/Ubuntu install (from this zip)
-------------------------------------

This zip contains the Debian/Ubuntu package plus helpers.

1. Install (from this folder, after unzip):

     sudo apt install ./Madek-Exporter_Linux-x64.deb
     # or: sudo apt install ./Madek-Exporter_Linux-ARM64.deb

2. Start Madek Exporter from the applications menu, or run:

     madek-exporter

Uninstall
---------

Run delete-app.sh from this folder:

  ./delete-app.sh

(or: sudo apt remove madek-exporter)
